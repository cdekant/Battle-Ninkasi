# Battle Ninkasi

Die Idee zu diesem Video-Spiel entstand irgendwann im Jahre 2025, die ernsthafte Entwicklung startete am 11. November 2026. Geprägt ist der Code durch die Entwicklung via Claude Code Opus 5.5. Das Modell setzte sämtlichen Code nach meinen Ideen und Vorstellungen in Umgangssprache auf.

Battle Ninkasi ist ein rundenbasiertes Roguelike, das das Thema Bierbrauen als eine zentrale Mechanik hat. Die Heldin ist Ninkasi, die sumerische Göttin des Bieres. In einem nach unten offenen Dungeon-Crawler muss sie eine Zeitreise vom alten Sumer bis in die Zukunft antreten um Sobrietas, die Göttin der Abstinenz, für alle Zeiten zu erledigen.

## Die Einzigartigkeit eines Runs

Vorbilder für die klassenlosen Builds, die in Battle Ninkasi möglich sind, lieferten vor allem EvE Online und Skyrim. Weitere Paten mit ausschlaggebenden Einflüssen in der Entwicklung waren Caves of Qud und Brogue. Ferner lieferten die folgenden Spiele Inspirationen: Dungeon Crawl Stone Soup, NetHack, Hades, Slay the Spire, und, irgendwie unerwartet: World of Warcraft.
